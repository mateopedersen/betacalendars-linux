# Privacy

Beta Calendars Studio computes dates and builds SVG layouts on the device. It does not collect or transmit personal calendar data, create accounts, send analytics, or run a background service.

The application does not connect to Evolution Data Server or other personal-calendar services. It does not have a network plug in its strict Snap manifest. The optional Resources page contains links; a page opens only after a user selects its link, using the desktop's standard URI handler.

SVG export uses GTK's portal-based file chooser. The user chooses the output file; the Snap does not request general access to the home directory.
