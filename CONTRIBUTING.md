# Contributing

Bug reports and focused pull requests are welcome.

Before opening a pull request:

1. Keep date arithmetic in `calendar_engine.py` so the GUI and CLI share one source of truth.
2. Add regression coverage for new calendar rules or boundary behavior.
3. Run the unit suite and formatting checks.
4. Update user documentation when a command or visible feature changes.

The project uses MIT licensing. By submitting a contribution, you agree that it may be distributed under that license.
